## 🚀 Getting Started

No build tools. No dependencies. Just open and go.

```bash
# 1. Clone the repository
git clone https://github.com/AdnanAli47/household-electricity-consumption-analyzer.git

# 2. Navigate into the project
cd household-electricity-consumption-analyzer

# 3. Open in your browser
start index.html
```

Or simply drag `index.html` into any modern browser. ✅

## 🎨 Tech Stack

- **Structure** — Semantic HTML5
- **Styling** — Vanilla CSS3 (custom properties, grid, flexbox, animations)
- **Logic** — Vanilla JavaScript (ES6+)
- **Fonts** — [Six Caps](https://fonts.google.com/specimen/Six+Caps) + [Manrope](https://fonts.google.com/specimen/Manrope) via Google Fonts

---

## 📐 Design Highlights

- 🖤 **Dark-first** aesthetic with `#000` base and `#b8ff45` acid-green accent
- 🌀 **Custom cursor** with blend-mode difference effect
- 📽️ **Reveal animations** on scroll via IntersectionObserver
- 🔤 **Six Caps display font** for bold editorial headings
- 📡 **Marquee ticker** for feature highlights
- 🧩 **CSS-only grain overlay** for tactile texture
